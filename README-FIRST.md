# IED Premium Asset Pack — Final

## Installation

Extract this ZIP directly into:

`C:\Users\Stuart\Projects\eep-student-showcase`

The ZIP begins with the `public` folder, so the images will be placed directly into the correct project folders.

## Folder structure

```text
public/
└── images/
    ├── ied-campus.png
    ├── eep-illustration.png
    ├── esl-illustration.png
    └── ied-premium/
        ├── asset-manifest.json
        ├── heroes/
        ├── mobile/
        └── cards/
```

## Formats

- Desktop heroes: WebP, 1600 × 900
- Mobile heroes: WebP, 900 × 1125
- Card images: WebP, 800 × 600
- Compatibility images: optimized PNG

## Design rules

- Keep all text as real HTML; no text is baked into the images.
- Desktop heroes use a left text column and the image as the right/full visual area.
- Mobile heroes stack the text above the mobile image.
- Use only a restrained readability gradient.
- Do not place the card images inside oversized pale boxes.
- Do not add fantasy glows, floating elements, or generated people.
- Homepage/About use realistic versions of the supplied school building.
- EEP focuses on books, workbooks, vocabulary, writing, and class learning.
- ESL balances literature, science, social studies, and performance arts.

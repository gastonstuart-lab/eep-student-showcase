# Traditional Chinese Copy Pack

> Planning document only. Baseline: `0583ac3a1b8d8ec156eda970954832259337e369`.
>
> This copy is written for a Taiwan school context. Use `繁體中文`, `國際教育處`, and precise programme/subject wording. Do not use wording that implies Taiwan is China.

## Style rules

- Keep `IED`, `EEP`, and `ESL` as programme abbreviations where useful.
- Use `學習中心` for “Learning Hub”.
- Use `成果展示` for broad learning showcase contexts.
- Use `作品展示` when specifically referring to student-created work.
- Use `專題` for student projects.
- Use `社會領域` for Social Studies.
- Use `語文` for Language Arts.
- Use `表演藝術` for Performance Arts.
- Use natural Taiwan Traditional Chinese, not word-for-word machine translation.
- Keep button labels concise.

# 16. Fallback behaviour

Use this exact logic:

1. English mode:
   - show English content.
2. Traditional Chinese mode:
   - show Traditional Chinese content when available;
   - otherwise show English content;
   - never show an empty heading or button.
3. Bilingual mode:
   - show English first;
   - show Traditional Chinese on a second line when available;
   - if Traditional Chinese is absent, show English once only.
4. Do not auto-translate student-authored project text.
5. Do not save blank Traditional Chinese values that override English content.

# 18. QA requirements

Check every added string in:

- English mode
- bilingual mode
- Traditional Chinese mode
- desktop
- tablet
- mobile

Reject the implementation if:

- a fixed public button remains English-only in Traditional Chinese mode;
- bilingual text is forced into one slash-separated line where it causes poor layout;
- a Chinese field displays blank instead of falling back to English;
- terminology differs between public and admin areas;
- the language toggle causes topbar overlap;
- Social Studies is omitted or translated inconsistently;
- wording implies Taiwan is China.

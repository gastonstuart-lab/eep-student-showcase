# Gold-standard rejection rule

Before any new visual is accepted:
1. Compare it directly with the approved J1 gold pages or J2 approved 1–10.
2. If it looks more generic, more templated, more like a normal PPT, less scientifically useful, or less polished, reject it.
3. Never substitute easy CSS/shape graphics for the primary science visual.
4. Never change the approved visual language after approval.
5. Build interactivity around the visual master; do not downgrade the visual master to fit the renderer.
